# StreamNest demonstration narration (approx. 3–4 minutes)

“Hello. This is StreamNest, my responsive video-streaming feature project. The goal is to enable secure login, modern video controls, community interaction, paid subscriptions, limited downloads, and synchronized viewing.”

“On the homepage you can search and select videos. The custom player supports playback, seeking, volume, fullscreen, double-click or double-tap to skip ten seconds, and the next-video button. The design adapts to mobile and tablet screens.”

“Next, I open the Account page and sign in using a code sent to my email. Users can change their username, appearance and privacy options. Auto appearance uses India time: the light theme between ten and twelve in the morning; dark outside that interval.”

“Under each video, users can post comments in selected languages, translate comments, like, dislike or report comments. Obvious abusive words, links, repetitive characters and duplicates are rejected; reported comments enter a database review queue rather than being deleted for dislikes.”

“The Downloads area shows my plan, allowance and past activity. Free users are allowed one video download each day, while Bronze, Silver and Gold offer progressively higher daily limits. The server and database check the quota rather than trusting the browser.”

“On the Plans page, payments run in Razorpay Test Mode. When a test payment is verified on the server, the user's subscription is updated. The Account page provides a printable transaction receipt.”

“Finally, the Watch Party page creates a room code. A second participant can join the room, and host playback is synchronized with Supabase Realtime. The group-call button opens Jitsi Meet, where participants can use available camera, microphone, chat and screen-sharing controls.”

“Here are my live Vercel site and GitHub repository, with setup notes and source files. Thank you.”
